# 2. SEO-Critical Pages (what actually needs to rank)

## 1️⃣ Home page ⭐

**Purpose**

* Rank for broad, competitive terms
* Establish trust immediately

**Primary SEO intent**

* *Residential Architect GTA*
* *Residential Architecture Studio Toronto*
* *Custom Home Architect Ontario*

**Why critical**

* This is your **authority hub**
* Internally links to all key services + portfolio

---

## 2️⃣ Architectural Design (Residential) ⭐

**This is your MOST important service page.**

**URL example**

```
/services/residential-architectural-design-gta
```

**Targets**

* residential architect GTA
* custom home architect Toronto
* residential architecture studio Ontario

**Content focus**

* Custom homes
* Renovations & additions
* Full-scope design (permits, zoning included)

This page should **clearly state**:

> “Architectural design includes zoning, feasibility, permits, coordination.”

So you don’t need separate SEO pages for every sub-service.

---

## 3️⃣ Interior Design ⭐

**URL example**

```
/services/interior-design-residential
```

**Targets**

* residential interior designer GTA
* interior architecture Toronto

**Why SEO-critical**

* Separate demand stream
* Often searched independently
* Strong upsell from architecture clients

---

## 4️⃣ Planning & Building Permits (supporting SEO)

**URL example**

```
/services/planning-building-permits
```

**Targets**

* building permit drawings Toronto
* zoning feasibility study Ontario

**Important note**
This page is **secondary SEO**, but very strong for:

* Educating first-time homeowners
* Capturing “small projects” traffic
* Demonstrating technical competence

👉 You *do not* need to push this as a main nav item if you want a minimalist menu — it can live under Services.

---

## 5️⃣ Portfolio – Project Index ⭐

**URL**

```
/portfolio
```

**SEO role**

* Ranks for brand + “projects”
* Feeds authority to project pages

Should allow filtering by:

* Year
* Project type (custom home / renovation)

---

## 6️⃣ Individual Project Pages ⭐⭐⭐ (MOST UNDERRATED SEO ASSET)

Each project = **its own SEO landing page**.

**URL example**

```
/projects/toronto-residential-renovation-2023
```

**Targets**

* residential architect Toronto (long-tail)
* renovation architect GTA
* neighborhood-level searches (later)

**Must include**

* City (not exact address)
* Year
* Client goals
* Design challenges
* Drawings / plans / renders (even few)

These pages quietly build **topical authority** over time.

---

## 7️⃣ About ⭐

**SEO + trust hybrid**

**Targets**

* Studio name
* “architecture studio Toronto” (brand-adjacent)

**Must include**

* Philosophy
* Process mindset
* Personal story (important for small studio)
* Credentials / experience

This aligns well with the examples you like (Sensus, Thirty by Forty).

---

## 8️⃣ Process (Supporting but important)

**URL**

```
/process
```

**Purpose**

* Reduce friction
* Educate first-time clients
* Improve conversions

Not a primary SEO page, but:

* Strong internal linking target
* Reinforces expertise

---

## 9️⃣ Insights / Articles (Optional, future SEO)

Only publish if content is **practical**, not theoretical.

Good early topics:

* “Do I need an architect for a residential renovation in Ontario?”
* “Architect vs designer: what homeowners in GTA should know”

This is **phase 2 SEO**, not mandatory at launch.

---

## 10️⃣ Contact / Book Consultation ⭐

**Conversion-critical**

**URL**

```
/contact
```

or

```
/book-consultation
```

SEO value is secondary, but:

* Must be linked from every page
* Clear CTA everywhere

---

# 3. What NOT to create (important)

To keep things clean and avoid thin pages:

❌ Separate pages for:

* Renders
* Small permits
* Feasibility only
* Zoning only

These live **inside service + project pages**.
